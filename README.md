Open and run `Day23_Final_Validation.ipynb` in Jupyter/Colab. Keep the Day 22 pipeline and source CSV in the same folder as the notebook. Runtime numbers depend on the execution environment.

See `Day23_Final_Validation_Report.md` for metrics, runtime, model size and limitations.
